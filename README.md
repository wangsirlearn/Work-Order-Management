# 工单管理与图表展示页面

## 项目概述

本项目是一个基于 Vue 3 + Ant Design Vue + ECharts 的工单管理系统，实现了工单列表展示、新增、删除功能以及项目工时图表可视化。

### 技术栈

- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI组件库**: Ant Design Vue 4.x
- **图表库**: ECharts 5.x
- **路由**: Vue Router 4
- **样式**: Less + CSS3

---

## 功能说明

### 1. 登录页
- 用户名/密码表单验证
- 权限区分：
  - `admin` → 管理员（可新增、删除工单）
  - 其他用户名 → 普通用户（仅查看）

### 2. 工单列表
- 展示工单数据：ID、项目名称、是否加班、工时、创建时间
- 初始化5条模拟数据
- 新增工单（对话框形式，仅管理员）
- 删除工单（确认对话框，仅管理员）
- 删除后自动重新排序

### 3. 图表展示
- 柱状图展示各项目累计工时
- 数据与表格实时联动
- X轴项目名称自动换行
- 柱子顶部显示数值

### 4. 权限控制
| 功能 | 管理员 | 普通用户 |
|------|--------|----------|
| 查看工单表格 | ✅ | ✅ |
| 新增工单 | ✅ | ❌ |
| 删除工单 | ✅ | ❌ |
| 查看图表 | ✅ | ✅ |
| 路由守卫 | ✅ | ✅ |

### 哪些代码由 AI 生成？你做了哪些修改？

#### AI 生成
- 项目完整结构搭建
- Vue 组件的基础代码
- Ant Design Vue 组件使用
- ECharts 图表配置
- 路由守卫逻辑

#### 人工修改（根据需求调整）
1. **图表 X 轴标签换行** - 初始显示不全，配置 `formatter` 实现自动换行
2. **ECharts 初始化时机** - 添加 `nextTick` 解决 DOM 未渲染问题
3. **新增工单位置** - 从头部插入改为尾部追加
4. **删除后 ID 重排** - 新增删除后序号重新排序逻辑
5. **权限控制优化** - 添加路由守卫、普通用户隐藏按钮

### 哪一部分你认为最难或最满意？

#### 最难处理的部分

1. **ECharts 初始化时机问题**
   - 问题：图表在 `onMounted` 时初始化，但图表容器 DOM 可能尚未渲染完成
   - 解决：使用 `nextTick` 确保 DOM 渲染后再初始化图表
   - 代码位置：`Home.vue` - `onMounted` 和 `watch` 中

2. **X 轴项目名称重叠**
   - 问题：项目名称较长时，X 轴标签重叠在一起
   - 解决：配置 `axisLabel.formatter` 实现自动换行
   - 代码位置：`Home.vue` - `initChart` 函数中

3. **删除后 ID 重排**
   - 问题：删除工单后，剩余工单的 ID 需要重新排序保持连续
   - 解决：删除后遍历数组重新赋值 ID
   - 代码位置：`Home.vue` - `handleDelete` 函数中

#### 最满意的部分

1. **权限控制实现**
   - 通过计算属性 `isAdmin` 动态判断用户角色
   - 结合 `v-if` 指令实现按钮的显示/隐藏
   - 普通用户操作列显示"无权限"提示
   - 代码简洁且易于维护

2. **图表与表格联动**
   - 使用 `watch` 监听 `workOrders` 数据变化
   - 配合 `deep: true` 实现深度监听
   - 数据增删改后图表自动更新
   - 用户体验流畅

3. **UI 样式设计**
   - 商务科技风（蓝紫渐变背景）
   - 磨砂玻璃效果卡片
   - 渐变色图表柱子
   - 符合原型图设计要求
